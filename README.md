Two lines that explain a toaster to a 10-year-old. Line 1 gives the everyday thing in one vivid sentence built on a surprising analogy: a toaster is a tiny sunbathing bed for bread, lying under hot glowing wires the way you lie on a warm beach towel. Line 2 says in one sentence why that analogy works, what it maps (steady heat from above browning the outside while the inside stays soft) and what it leaves out (bread cannot move into the shade or put on sunscreen). The program writes exactly those two lines (358 characters) to `entry.txt`, validated against the gate: UTF-8 text, 1 to 400 characters, exactly two lines.

## Run it

```sh
python3 main.py
```

By default the entry is written to `/output/entry.txt`; set `MAKEFUN_OUTPUT_DIR` to write it elsewhere, e.g. `MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py`.
